# GitHub Portfolio Analyzer

**GitHub Portfolio Analyzer** is a web application built with **Next.js** that allows users to analyze any GitHub profile.  
It provides a clean and organized overview of repositories, activity, and key metrics to help visualize a developer’s portfolio.

## 🚀 Features
- Search and view any GitHub user’s profile  
- Display repositories, followers, and contributions  
- Responsive and minimal UI

## ⚙️ Getting Started

1. Clone the repository  
```bash
git clone https://github.com/IFTE-13/Github-Portfolio-Analyzer.git
```

2. Navigate to the project directory
```bash
 cd Github-Portfolio-Analyzer
```
3. Install dependencies (choose any one)
```bash
npm install
```
```bash
pnpm install
```
4. Run the development server (choose based on the previos selection)
```bash
npm run dev
```
```bash
pnpm run dev
```
5. Open http://localhost:3000 in your browser.
